# .NET for Apple platforms error/warning BI1116

## Issue

The parameter '\*' in the delegate '\*' does not have a [CCallback] or [BlockCallback] attribute. Defaulting to [CCallback]. Declare a custom delegate instead of using System.Action / System.Func and add the attribute on the corresponding parameter.
