# .NET for Apple platforms warning MT7158

## Issue

The {0} item '{1}' has been included more than once, with different 'LogicalName' metadata: {2}, {3}.

The resource collector identifies the same physical file in multiple items with different logical names. Only its first occurrence is retained.

## Solution

Remove duplicate includes and give the resource one consistent `LogicalName`. Check explicit entries, wildcard imports and, for local builds, symbolic links that resolve to the same file.
