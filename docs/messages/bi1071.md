# .NET for Apple platforms error/warning BI1071

## Issue

The BindAs type for the member "\*.\*" must be an array when the member's type is an array. See example binding below.

## Solution

Correct:

```csharp
[BindAs (typeof (string []))]
[Export ("stringProp")]
NSString[] StringProp { get; }
```

Incorrect:

```csharp
[BindAs (typeof (string))]
[Export ("stringProp")]
NSString[] StringProp { get; }
```
