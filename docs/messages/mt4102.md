# .NET for Apple platforms error/warning MT4102

## Issue

The registrar found an invalid type `*` in signature for method `*`. Use `*` instead.

## Solution

This currently only happens with one type: System.DateTime. Use the Objective-C equivalent (NSDate) instead.
