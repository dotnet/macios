# .NET for Apple platforms error BI9999

## Issue

The binding generator expected an attribute to be present, but the attribute lookup returned no matches. This internal error path currently has no dedicated message resource, so the output reports that the message for BI9999 could not be found.

## Solution

Review earlier diagnostics for an invalid binding declaration. If no earlier diagnostic explains the failure, report the complete output and a minimal binding definition that reproduces it. The missing message itself should also be reported.
