# .NET for Apple platforms error/warning MT1021

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not copy the file '\*' to '\*': {2}

## Solution

A file could not be copied. The error message from the copy operation has more information about the error.
