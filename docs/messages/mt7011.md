# .NET for Apple platforms error/warning MT7011

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The WatchKit Extension '*' has an invalid Info.plist: the NSExtension dictionary does not contain an NSExtensionAttributes dictionary.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
