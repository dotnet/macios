# .NET for Apple platforms error/warning BI1055

## Issue

Internal error: failed to convert type '\*'. Please file a bug report (https://github.com/dotnet/macios/issues/new) with a test case.

## Solution

This usually indicates a bug in the product; please [file a bug report](https://github.com/dotnet/macios/issues/new) with a test case.
