# .NET for Apple platforms error/warning MT8023

## Issue

An instance object is required to construct a closed generic method for the open generic method: \* (token reference: \*)..

## Solution

This indicates a bug in Xamarin.iOS. Please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new).
