# .NET for Apple platforms error/warning MT4178

## Issue

The class '{class}' will not be registered because the WatchKit framework has been removed from the iOS SDK.

## Solution

Apple removed the WatchKit framework from the iOS SDK, so any code that uses it will not compile anymore.

Any code that uses the WatchKit framework must be removed/rewritten.

Reference: https://github.com/dotnet/macios/issues/6492
