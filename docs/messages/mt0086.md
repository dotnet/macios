# .NET for Apple platforms error/warning MT0086

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

A target framework (--target-framework) must be specified when building for TVOS or WatchOS.

## Solution

This indicates a bug in Xamarin.iOS. Please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new).
