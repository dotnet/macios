# .NET for Apple platforms error/warning MT0019

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Only one --[log|install|kill|launch]dev or --[launch|debug]sim option can be used.

## Solution

There are several options for mtouch that can't be used simultaneously:

- --logdev
- --installdev
- --killdev
- --launchdev
- --launchdebug
- --launchsim
