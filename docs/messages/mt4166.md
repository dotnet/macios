# .NET for Apple platforms error/warning MT4166

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Cannot register the method '\*' because the signature contains a type (\*) that isn't a reference type.

## Solution

This usually indicates a bug in Xamarin.iOS. Please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new).
