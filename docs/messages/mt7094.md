# .NET for Apple platforms error MT7094

## Issue

The file or directory '{0}' is not a framework nor a file within a framework.

An item classified as `AppleFramework` could not be associated with a framework directory.

## Solution

Check the native reference and any custom `ResolvedFileToPublish` items. An item with `PublishFolderType` set to `AppleFramework` must identify a framework or a file inside one. Correct its path or use the publish folder type appropriate to the item.
