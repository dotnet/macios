# .NET for Apple platforms error/warning MT5307

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to sign the executable. Please review the build log.

## Solution

An error occurred when signing the application. Please review the build log to see the error reported by 'codesign'.
