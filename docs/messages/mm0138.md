# .NET for Apple platforms error/warning MM0138

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Building 32-bit apps is not possible when using Xcode 10. Please migrate project to the Unified API.

## Solution

Xcode 10 does not support building 32-bit applications.

The project must be [migrated to a Unified project](https://docs.microsoft.com/en-us/xamarin/cross-platform/macios/unified/updating-mac-apps) in order to support 64-bit.
