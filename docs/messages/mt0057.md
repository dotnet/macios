# .NET for Apple platforms error/warning MT0057

## Issue

Cannot determine the path to Xcode.app from the sdk root '*'. Please specify the full path to the Xcode.app bundle.

## Solution

The path passed using `--sdkroot` does not specify a valid Xcode app. Please specify a path to an Xcode app.
