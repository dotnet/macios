# .NET for Apple platforms error MT7091

## Issue

File '{0}' is not a valid framework: {1}

The framework filtering task could not inspect the framework executable. The final part of the message contains the underlying failure.

## Solution

Verify that the referenced file is a valid Mach-O framework executable for the target platform. Check the framework's `Info.plist` and executable path, and restore or rebuild the native dependency if its contents are damaged.

This error is emitted as MT7091 even though its localized message resource is named `E7092`.
