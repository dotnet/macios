# .NET for Apple platforms error/warning MT1304

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The embedded framework '\*' in \* is invalid: it does not contain an Info.plist.

## Solution

The specified embedded framework does not contain an Info.plist, and is therefore not a valid framework.

Please make sure the framework is valid.
