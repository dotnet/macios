# .NET for Apple platforms error/warning MT3003

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Conflicting --debug and --llvm options. Soft-debugging is disabled.

## Solution

Debugging is not supported when LLVM is enabled. If you need to debug the app, disable LLVM first.
