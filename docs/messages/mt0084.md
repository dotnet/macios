# .NET for Apple platforms error/warning MT0084

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Bitcode is not supported in the simulator. Do not pass --bitcode when building for the simulator.
