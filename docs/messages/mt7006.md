# .NET for Apple platforms error/warning MT7006

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The App Extension '\*' has an invalid CFBundleIdentifier (\*), it does not begin with the main app bundle's CFBundleIdentifier (*).

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
