# .NET for Apple platforms error MT7157

## Issue

The {0} item '{1}' does not have a 'LogicalName' metadata.

The resource's logical name is empty, so the build cannot determine its destination in the app bundle.

## Solution

Check the resource item and any custom targets that create or transform it. Supply a nonempty `LogicalName` identifying its path in the app bundle, and ensure later item transformations preserve that metadata.
