# .NET for Apple platforms error/warning MT1031

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not launch the app '\*' on the device '\*' because the device is locked. Please unlock the device and try again.

## Solution

Please unlock the device and try again.
