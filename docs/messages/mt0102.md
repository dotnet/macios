# .NET for Apple platforms error/warning MT0102

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The assemblies '\*' and '\*' have the same target name ('\*'), but different targets ('\*' and '*').

## Solution

The assemblies mentioned in the error message have conflicting build targets.

For example:

```
  --assembly-build-target:Assembly1.dll=framework=MyBinary --assembly-build-target:Assembly2.dll=dynamiclibrary=MyBinary
```

This example is trying to create both a dynamic library and a framework with the same make (`MyBinary`).
