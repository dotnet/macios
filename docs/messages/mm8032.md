# .NET for Apple platforms error/warning MM8032

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Unable to convert from a managed array of {type} to an NSArray.

## Solution

This usually indicates a bug in Objective-C binding code.

If the managed binding is from a third-party vendor, please contact the vendor.

If the managed binding is shipped with Xamarin.Mac, please [submit an issue](https://github.com/dotnet/macios/wiki/Submitting-Bugs-&-Suggestions).
