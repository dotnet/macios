# .NET for Apple platforms error/warning MT0042

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

No reference to either monotouch.dll or Xamarin.iOS.dll was found. A reference to monotouch.dll will be added.
