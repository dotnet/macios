# .NET for Apple platforms error/warning MT0044

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

--listsim is only supported with Xcode 6.0 or later.

## Solution

Install a newer Xcode version.
