# .NET for Apple platforms error/warning MM0139

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Building 32-bit apps is not possible when using Xcode 10. Please change the architecture in the project's Mac Build options to 'x86_64'.

## Solution

Xcode 10 does not support building 32-bit applications.

Change the architecture in the project's Mac Build options to 'x86_64' in order to build a 64-bit application.
