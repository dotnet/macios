# .NET for Apple platforms error/warning MT0015

## Issue

Invalid ABI: *. Supported ABIs are: i386, x86_64,  armv7, armv7+llvm, armv7+llvm+thumb2, armv7s, armv7s+llvm, armv7s+llvm+thumb2, arm64 and arm64+llvm.

## Solution

An invalid ABI was passed to mtouch. Please specify a valid ABI.
