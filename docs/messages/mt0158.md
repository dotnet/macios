# .NET for Apple platforms error/warning MT0158

## Issue

The file '{0}' does not exist.

The framework filtering task could not find the referenced framework executable.

## Solution

Check the framework path and its `CFBundleExecutable` entry in `Info.plist`. Ensure the executable exists in the supplied framework, and restore or rebuild the native dependency if it is missing.

## Historical message

Older tooling also used this code for:

Internal error: the smart enum {0} doesn't seem to be a smart enum after all. Please file a bug report with a test case (https://github.com/dotnet/macios/issues/new).

Recovery guidance for this historical message has not yet been documented.
