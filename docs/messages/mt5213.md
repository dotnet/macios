# .NET for Apple platforms error/warning MT5213

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Duplicate symbol in: * (Location related to previous error)

## Solution

This error is reported only together with [MT5212](mt5212.md). Please see [MT5212](mt5212.md) for more information.
