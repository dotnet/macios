# .NET for Apple platforms error/warning MT0087

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Incremental builds (--fastdev) is not supported with the Boehm GC. Incremental builds will be disabled.
