# .NET for Apple platforms error/warning MT1016

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to create the NOTICE file because a directory already exists with the same name.

## Solution

Remove the directory `NOTICE` from the project.

Earlier versions of our tools generated a NOTICE file.
