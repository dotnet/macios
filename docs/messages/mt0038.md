# .NET for Apple platforms error/warning MT0038

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The old registrars (--registrar:oldstatic|olddynamic) are not supported when referencing Xamarin.iOS.dll.
