# .NET for Apple platforms error/warning MT0062

## Issue

No Xcode.app specified (using --sdkroot or 'xcode-select --print-path'), using the default Xcode instead: *

## Solution

This is a informational warning, explaining which Xcode will be used, since none was specified.
