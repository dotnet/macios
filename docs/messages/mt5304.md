# .NET for Apple platforms error/warning MT5304

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to strip the final binary. Please review the build log.

## Solution

An error occurred when running the 'strip' tool to remove debugging information from the application.
