# .NET for Apple platforms error/warning BI1014

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

> [!IMPORTANT]
> New builds use [BI1906](bi1906.md) for this binding diagnostic. The old code remains documented for existing build logs. Update any warning-code configuration when upgrading.

## Issue

Unsupported type for Fields: \* for '\*'.

## Solution

Please go to [[FieldAttribute]](https://developer.xamarin.com/guides/cross-platform/macios/binding/binding-types-reference/#FieldAttribute) documentation to see supported types.
