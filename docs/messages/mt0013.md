# .NET for Apple platforms error/warning MT0013

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Profiling support requires sgen to be enabled too.

## Solution

SGen (--sgen) must be enabled if profiling (--profiling) is enabled.
