# .NET for Apple platforms warning MT7154

## Issue

The {0} item '{1}' imported from '{2}' was ignored, because there's already an existing item from the current project with the same LogicalName ('{3}')

The project resource is included instead of the imported resource.

## Solution

Check whether the override is intentional. If both resources are needed, give them distinct `LogicalName` metadata so they have different paths in the app bundle. Otherwise remove the duplicate resource or adjust the dependency that supplies it.
