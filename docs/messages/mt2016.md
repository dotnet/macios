# .NET for Apple platforms error/warning MT2016

## Issue

Keeping the dynamic registrar (by passing '--optimize=-remove-dynamic-registrar') is not possible, because the dynamic registrar is not supported when using NativeAOT. Support for dynamic registration will still be removed.

## Solution

NativeAOT does not support dynamic registration. Remove the `--optimize=-remove-dynamic-registrar` override. The build removes dynamic registration regardless of this override when NativeAOT is enabled.

## Historical message

Older tooling also used this code for:

Invalid TlsProvider `legacy` option. The only valid value `appletls` will be used.

### Historical solution

The `legacy` provider, which was a fully managed SSLv3 / TLSv1 only provider, is not shipped with Xamarin.iOS anymore. Projects that were using this old provider and now build with the newer `appletls` one.

To fix this warning, open the project file in a text editor, and remove all `MtouchTlsProvider`` nodes from the XML.
