# .NET for Apple platforms error MT7138

## Issue

Invalid value '{0}' for the 'ValidateEntitlements' property. Valid values are: 'disable', 'warn' or 'error'.

## Solution

Set the `ValidateEntitlements` MSBuild property to `error`, `warn` or `disable`, or remove the override to use the default error behavior. Values are case-insensitive. Prefer `error` unless the project intentionally needs a different entitlement validation policy.
