# .NET for Apple platforms error/warning MT5303

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to generate the debug symbols (dSYM directory). Please review the build log.

## Solution

An error occurred when running dsymutil on the final .app directory to create the debug symbols. Please review the build log to see dsymutil's output and see how it can be fixed.
