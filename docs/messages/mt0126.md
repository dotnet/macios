# .NET for Apple platforms error/warning MT0126

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Incremental builds have been disabled because incremental builds are not supported in the simulator.

## Solution

No action is required, this message is purely informational.
