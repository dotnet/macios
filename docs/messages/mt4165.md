# .NET for Apple platforms error/warning MT4165

## Issue

The registrar couldn't find the type 'System.Void' in any of the referenced assemblies.

## Solution

This error most likely indicates a bug in Xamarin.iOS. Please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new).
