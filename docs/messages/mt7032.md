# .NET for Apple platforms error/warning MT7032

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The WatchKit Extension '*' has an invalid Info.plist: UIRequiredDeviceCapabilities should not contain the 'watch-companion' capability.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
