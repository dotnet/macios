# .NET for Apple platforms error/warning MT2017

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not process XML description.

## Solution

This means there is an error on the [custom XML linker configuration file](https://learn.microsoft.com/previous-versions/xamarin/cross-platform/deploy-test/linker.md) you provided, please review your file.
