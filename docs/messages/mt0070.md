# .NET for Apple platforms error/warning MT0070

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Invalid target framework: *. Valid target frameworks are: *.

## Solution

An invalid target framework was passed using the --target-framework argument. Please specify a valid target framework.
