# .NET for Apple platforms error/warning MT1028

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Invalid device specification: '*'. Expected 'ios', 'watchos' or 'all'.

## Solution

The device specification passed using --device is invalid. Valid values are: 'ios', 'watchos' or 'all'.
