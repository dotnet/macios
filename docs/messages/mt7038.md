# .NET for Apple platforms error/warning MT7038

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The Watch App '*' has an invalid Info.plist: the WKCompanionAppBundleIdentifier must exist and must match the main app bundle's CFBundleIdentifier.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
