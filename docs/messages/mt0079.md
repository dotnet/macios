# .NET for Apple platforms error/warning MT0079

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The recommended Xcode version for Xamarin.iOS \* is Xcode \* or later. The current Xcode version (found in \*) is \*.

## Solution

This is a warning informing that the current version of Xcode is not the recommended version of Xcode for this version of Xamarin.iOS.

Please upgrade Xcode to ensure optimal behavior.
