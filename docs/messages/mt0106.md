# .NET for Apple platforms error/warning MT0106

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The assembly build target name '\*' is invalid: the character '\*' is not allowed.

## Solution

The assembly build target name must be a valid filename.

For example these values will trigger this error:

```
--assembly-build-target:Assembly1.dll=staticobject=my/path.o
```

because `my/path.o` is not a valid filename due to the directory separator character.
