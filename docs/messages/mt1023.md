# .NET for Apple platforms error/warning MT1023

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not communicate with the device to find the application '\*' : \*

## Solution

An error occurred when trying to lookup an application on device.

Things to try to solve this:

- Delete the application from the device and try again.
- Disconnect the device and reconnect it.
- Reboot the device.
- Reboot the Mac.
