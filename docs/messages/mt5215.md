# .NET for Apple platforms error/warning MT5215

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

References to '*' might require additional -framework=XXX or -lXXX instructions to the native linker

## Solution

This is a warning, indicating that a P/Invoke was detected to reference the library in question, but the app is not linking with it.
