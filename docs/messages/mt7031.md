# .NET for Apple platforms error/warning MT7031

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The Watch Extension '*' has an invalid Info.plist: the NSExtensionAttributes dictionary must contain a WKAppBundleIdentifier.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
