# .NET for Apple platforms error/warning MT7029

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The Watch Extension '*' has an invalid Info.plist: the NSExtensionPointIdentifier must be "com.apple.watchkit".

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
