# .NET for Apple platforms error/warning MT7026

## Issue

The Watch Extension '\*' has an invalid CFBundleIdentifier (\*), it does not begin with the main app bundle's CFBundleIdentifier (*).

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
