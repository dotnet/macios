# .NET for Apple platforms error/warning MT7010

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The App Extension '*' has an invalid Info.plist: the NSExtension dictionary does not contain an NSExtensionPointIdentifier value.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
