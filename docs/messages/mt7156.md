# .NET for Apple platforms warning MT7156

## Issue

The {0} item '{1}' was ignored, because there's another item with the same LogicalName ('{2}')

Multiple project resources have the same logical name. The conflicting items are omitted rather than choosing an arbitrary resource.

## Solution

Remove duplicate resource items or assign distinct `LogicalName` metadata. Check both explicit project entries and wildcard or imported item declarations that may include a resource a second time.
