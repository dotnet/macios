# .NET for Apple platforms error/warning MT0064

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Xamarin.iOS only supports embedded frameworks with Unified projects.

## Solution

Xamarin.iOS only supports embedded frameworks when using the Unified API; please update your project to use the Unified API.
