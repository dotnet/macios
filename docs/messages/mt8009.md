# .NET for Apple platforms error/warning MT8009

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Unable to locate the block to delegate conversion method for the method *.*'s parameter #*.

## Solution

This indicates an API wasn't bound correctly. If this is an API exposed by Xamarin, please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new). If it's a third-party binding, please contact the vendor.
