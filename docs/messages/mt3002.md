# .NET for Apple platforms error/warning MT3002

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

AOT restriction: Method '*' must be static since it is decorated with [MonoPInvokeCallback]. See [developer.xamarin.com/guides/ios/advanced_topics/limitations/#Reverse_Callbacks](https://learn.microsoft.com/previous-versions/xamarin/ios/internals/limitations.md#reverse-callbacks)

## Solution

This error message comes from the AOT compiler.
