# .NET for Apple platforms error/warning MT0137

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Cannot find the assembly {assembly}, referenced by an attribute in {assembly}.

## Solution

This warning occurs when an attribute contains a reference to another assembly
that can't be found.

mtouch may in certain cases still find references at a later point, which
means that if the build otherwise succeeds, this warning can be ignored.
