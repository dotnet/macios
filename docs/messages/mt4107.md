# .NET for Apple platforms error/warning MT4107

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The registrar cannot marshal the parameter of type `*` in signature for method `+`.

## Solution

A type was found in exported API that the runtime doesn't know how to marshal to/from Objective-C.

If you believe Xamarin.iOS should support the type in question, please file an enhancement request on [GitHub](https://github.com/dotnet/macios/issues/new).
