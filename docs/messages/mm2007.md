# .NET for Apple platforms error/warning MM2007

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Xamarin.Mac Unified API against a full .NET profile does not support linking. Pass the -nolink flag.
