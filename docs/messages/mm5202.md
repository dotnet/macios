# .NET for Apple platforms error/warning MM5202

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Mono.framework MDK is missing. Please install the MDK for your Mono.framework version from https://mono-project.com/Downloads
