# .NET for Apple platforms error/warning MT1110

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Application failed to launch because of iOS security restrictions. Please ensure the developer is trusted.

## Solution

If you're deploying an enterprise app or using a free provisioning profile, you might have trust the developer (this is explained <a href="https://stackoverflow.com/a/30726375/183422">here</a>).
