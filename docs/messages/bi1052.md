# .NET for Apple platforms error/warning BI1052

## Issue

Internal error: Could not find the type \* in the assembly \*. Please file a bug report (https://github.com/dotnet/macios/issues/new) with a test case.

## Solution

This usually indicates a bug in the product; please [file a bug report](https://github.com/dotnet/macios/issues/new) with a test case.
