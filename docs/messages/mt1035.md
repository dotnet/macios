# .NET for Apple platforms error/warning MT1035

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Cannot include different versions of the framework '{name}'

## Solution

It is not possible to link with different versions of the same framework.

This typically happens when an extension references a different version of a framework than the container app (possibly through a third-party binding assembly).

Following this error there will be multiple [MT1036](mt1036.md) errors listing the paths for each different framework.
