# .NET for Apple platforms error/warning MT4002

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to compile the generated code for P/Invoke methods.

## Solution

Failed to compile the generated code for P/Invoke methods. Please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new).
