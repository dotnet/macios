# .NET for Apple platforms error/warning MT0012

## Issue

Could not parse TargetArchitectures '{0}'

The native linker task could not parse its target architecture setting.

## Solution

Check the runtime identifier and any custom targets that set the `LinkNativeCode` task's `TargetArchitectures` parameter. Use an architecture supported by the selected Apple platform.

## Historical message

Older Xamarin tooling also used this code for:

Incomplete data is provided to complete *.

### Historical solution

This error is not reported anymore in the current version of Xamarin.iOS.
