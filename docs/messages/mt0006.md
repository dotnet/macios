# .NET for Apple platforms error/warning MT0006

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

There is no devel platform at *, use --platform=PLAT to specify the SDK.

## Solution

Xamarin.iOS cannot find the SDK directory at the location mentioned in the error message. Please verify that the path is correct.
