# .NET for Apple platforms error/warning MT0083

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Asm-only bitcode is not supported on watchOS. Use either --bitcode:marker or --bitcode:full.
