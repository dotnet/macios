# .NET for Apple platforms error/warning MT2006

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Can not load mscorlib.dll from: *. Please reinstall Xamarin.iOS.

## Solution

This generally indicates that there is a problem with your Xamarin.iOS installation. Please try reinstalling Xamarin.iOS.
