# .NET for Apple platforms error/warning MT5306

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Failed to create the a fat library. Please review the build log.

## Solution

An error occurred when running the 'lipo' tool. Please review the build log to see the error reported by 'lipo'.
