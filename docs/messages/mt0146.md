# .NET for Apple platforms error/warning MT0146

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

ARM64_32 Debug mode requires --interpreter[=all], forcing it.

## Solution

This warning is shown when `--interpreter` isn't specified explicitly for ARM64_32 Debug builds. The AOT compiler can't be used because it doesn't support ARM64_32.
