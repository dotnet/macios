# .NET for Apple platforms error/warning MT5219

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Not linking with {framework} because it has been removed from {platform}.

## Solution

The framework in question has been removed, and Xamarin.iOS can't link with it.

Any code that uses the framework must be removed/rewritten.
