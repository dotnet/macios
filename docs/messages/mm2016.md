# .NET for Apple platforms error/warning MM2016

## Issue

Keeping the dynamic registrar (by passing '--optimize=-remove-dynamic-registrar') is not possible, because the dynamic registrar is not supported when using NativeAOT. Support for dynamic registration will still be removed.

## Solution

NativeAOT does not support dynamic registration. Remove the `--optimize=-remove-dynamic-registrar` override. The build removes dynamic registration regardless of this override when NativeAOT is enabled.

## Historical message

Older tooling also used this code for:

Invalid TlsProvider `{0}` option. The only valid value `{1}` will be used.

Recovery guidance for this historical message has not yet been documented.
