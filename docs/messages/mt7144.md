# .NET for Apple platforms warning MT7144

## Issue

Did not extract {0} because it would write outside the target directory.

An archive entry would resolve outside the intended extraction directory, so the build skipped it.

## Solution

Inspect the archive supplied by the native dependency or package. Recreate it with relative entry paths contained within the archive root, or obtain a corrected archive from its publisher. Do not bypass the extraction path check.
