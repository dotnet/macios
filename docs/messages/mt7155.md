# .NET for Apple platforms warning MT7155

## Issue

The {0} item '{1}' imported from '{2}' was ignored, because there's another item from a different assembly ({4}) with the same LogicalName ('{3}')

When multiple imported resources share a logical name and there is no project resource overriding them, none of the conflicting imported resources is included.

## Solution

Remove the duplicate dependency or change the conflicting resource names in the libraries. If the application should provide the resource, include exactly one project resource with the required logical name.
