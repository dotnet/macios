# Macios CI pwsh scripts.

The macios contains several pwsh modules. This makes it easy to organize code based on the type of cmdlets it provides.
Along with each module, there is a Test script that contains the pester tests for the cmdlets. To make things easier in yaml
all the modules can be imported using a pwsh manifest, which is found at MaciosCI.psd1 

The MaciosCI.psd1 manifest is autogenerated using the script CreateManifest.ps1 as follows:
```bash
CreateManifest.ps1 -ManifestPath "/output/path.psd1"
```

The manifest only needs to be recreated when you add a new module that you want to be able to import in yaml.

## PR checkout

`undo_github_merge.ps1` checks out the second parent of `Build.SourceVersion`,
the PR head captured by GitHub's merge commit when the build was queued. The
local branch uses `System.PullRequest.SourceBranch` (without `refs/heads/`),
so the checkout retains the PR's source branch name rather than a detached HEAD.
It must not fetch the live PR head: a PR can advance while jobs are waiting to start,
and every job must use the same source revision as the packages it consumes.
Non-PR builds keep their current checkout.

The checkout template fetches full history so the queued merge's parents are
available. The script requires PowerShell 7.4 or newer for native Git command
failures to terminate the step.
