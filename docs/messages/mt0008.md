# .NET for Apple platforms error/warning MT0008

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

You should provide one root assembly only, found # assemblies: *.

## Solution

More than one root assembly was passed to mtouch, while there can be only one root assembly.
