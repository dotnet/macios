# .NET for Apple platforms error/warning MT0029

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

REPL (--enable-repl) is only supported in the simulator (--sim).

## Solution

REPL is only supported if you're building for the simulator. This means that if you pass `--enable-repl` to mtouch, you must also pass `--sim`.
