# .NET for Apple platforms error/warning MT8031

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Unable to convert from an NSArray to a managed array of {type}.

## Solution

This usually indicates a bug in Objective-C binding code.

If the managed binding is from a third-party vendor, please contact the vendor.

If the managed binding is shipped with Xamarin.iOS, please [submit an issue](https://github.com/dotnet/macios/wiki/Submitting-Bugs-&-Suggestions).
