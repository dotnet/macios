# .NET for Apple platforms error/warning MT6002

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not strip assembly `*`.

## Solution

An error occurred when stripping managed code(removing the IL code) from the assemblies in the application.
