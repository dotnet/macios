# .NET for Apple platforms error/warning BI1057

## Issue

Internal error: failed to instantiate mock attribute '\*' (could not convert constructor type #\* (\*)). Please file a bug report (https://github.com/dotnet/macios/issues/new) with a test case.

## Solution

This usually indicates a bug in the product; please [file a bug report](https://github.com/dotnet/macios/issues/new) with a test case.
