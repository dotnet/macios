# .NET for Apple platforms error/warning MT0025

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

No SDK version was provided. Please add `--sdk=X.Y` to specify which iOS SDK should be used to build your application.
