# .NET for Apple platforms error/warning MT3008

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Bitcode support requires the use of the LLVM AOT backend (--llvm)

## Solution

Bitcode support requires the use of the LLVM AOT backend (--llvm).

Either disable Bitcode support or enable LLVM.
