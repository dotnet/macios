# .NET for Apple platforms error/warning MT1027

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Can't use Xcode 7+ to launch applications on devices with iOS * (Xcode 7 only supports iOS 6+).

## Solution

It is not possible to use Xcode 7+ to launch applications on devices with iOS version below 6.0.

Please use an older version of Xcode, or tap on the app manually to launch it.
