# .NET for Apple platforms error/warning MT0061

## Issue

No Xcode.app specified (using --sdkroot), using the system Xcode as reported by 'xcode-select --print-path': *

## Solution

This is a informational warning, explaining which Xcode will be used, since none was specified.
