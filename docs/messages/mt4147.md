# .NET for Apple platforms error/warning MT4147

## Issue

Invalid {0} found on '{1}'. Please file a bug report at https://github.com/dotnet/macios/issues/new

## Solution

The registrar found an unsupported or invalid protocol attribute value. Check the reported attribute and type, including any `FormalSince` version. If the declaration is valid, file a bug report with the binding definition and the full diagnostic.

## Historical message

Older tooling also used this code for:

Detected a protocol inheriting from the JSExport protocol while using the dynamic registrar. It is not possible to export protocols to JavaScriptCore dynamically; the static registrar must be used (add '--registrar:static to the additional mtouch arguments in the project's iOS Build options to select the static registrar).

Recovery guidance for this historical message has not yet been documented.
