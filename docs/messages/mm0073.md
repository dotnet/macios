# .NET for Apple platforms error/warning MM0073

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Xamarin.Mac \* does not support a deployment target of \* (the minimum is \*). Please select a newer deployment target in your project's Info.plist.

## Solution

The minimum deployment target is the one specified in the error message; please select a newer deployment target in the project's Info.plist.

If updating the deployment target is not possible, then please use an older version of Xamarin.Mac.
