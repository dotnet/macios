# .NET for Apple platforms error/warning MT1029

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not find an application at the specified directory: *

## Solution

The application path passed to --launchdev does not exist. Please specify a valid app bundle.
