# .NET for Apple platforms error/warning MT0005

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The output directory * does not exist.

## Solution

Please create the directory.

This error is not generated anymore, mtouch will automatically create the directory if it doesn't exist.
