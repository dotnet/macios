# .NET for Apple platforms error/warning MT0088

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The GC must be in cooperative mode for watchOS apps. Please remove the --coop:false argument to mtouch.

## Solution

Note: this error is not applicable in .NET.
