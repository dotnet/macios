# .NET for Apple platforms error/warning MT1109

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Application failed to launch because the device is locked. Please unlock the device and try again.

## Solution

Please check if your device is locked.
