# .NET for Apple platforms error/warning MT1009

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not copy the assembly '\*' to '\*': *

## Solution

This is a known issue in certain versions of Xamarin.iOS.

If this occurs to you, try the following workaround:

```bash
sudo chmod 0644 /Library/Frameworks/Xamarin.iOS.framework/Versions/Current/lib/mono/*/*.mdb
```

However, since this issue has been resolved in the latest version of
Xamarin.iOS, please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new)
with your full version information and build log output.
