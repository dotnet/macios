# .NET for Apple platforms error/warning MT7020

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The Watch App '*' has an invalid Info.plist: the WKWatchKitApp key must be present and have a value of 'true'.

## Solution

*MSBuild task: ValidateAppBundleTaskBase*
