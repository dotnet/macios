# .NET for Apple platforms error/warning MT0016

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

The option * has been deprecated.

## Solution

The mentioned mtouch option has been deprecated and will be ignored.
