# .NET for Apple platforms error/warning MM0144

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Building 32-bit apps is not supported anymore. Please change the architecture in the project's Mac Build options to 'x86_64'.

## Solution

This version of Xamarin.Mac does not support building 32-bit applications.

Change the architecture in the project's Mac Build options to 'x86_64' in order to build a 64-bit application.
