# .NET for Apple platforms error/warning MT1303

## Issue

Could not decompress the native framework '\*' from '\*'. Please review the build log for more information from the native 'zip' command.

## Solution

Could not decompress the specified native framework from the binding library.

Please review the bulid log for more information about this failure from the native 'zip' command.
