# .NET for Apple platforms error/warning MT1220

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Could not find the latest simulator runtime for device '*'.

## Solution

This usually indicates a problem with Xcode.

Things to try to fix this:

- Use the simulator once in Xcode.
- Pass an explicit SDK version using --sdk \<version>.
- Reinstall Xcode.
