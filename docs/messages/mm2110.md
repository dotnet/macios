# .NET for Apple platforms error/warning MM2110

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Xamarin.Mac 'Partial Static' registrar does not support linking. Disable linking or use another registrar mode.
