# .NET for Apple platforms error/warning MT4164

## Issue

Cannot export the property '\*' because its selector '\*' is an Objective-C keyword. Please use a different name.

## Solution

The selector for the property in question is not a valid Objective-C identifer.

Please use a valid Objective-C identifier as selectors.
