# .NET for Apple platforms error/warning MT0142

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Cannot find the assembly '{assembly}', passed as an argument to --interpreter.

## Solution

This warning is shown if the assemblies names given to the `--interpreter` option (either to interpret them or not) cannot be found.
