# .NET for Apple platforms error/warning MT4168

## Issue

Cannot register the type '{managed\_name}' because its Objective-C name '{exported\_name}' is an Objective-C keyword. Please use a different name.

## Solution

The Objective-C name for the type in question is not a valid Objective-C identifier.

Please use a valid Objective-C identifier.
