# .NET for Apple platforms error/warning MT0076

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

No architecture specified (using the --abi argument). An architecture is required for * projects.

## Solution

This usually indicates a bug in Xamarin.iOS; please file a new issue on [GitHub](https://github.com/dotnet/macios/issues/new) with a test case.
