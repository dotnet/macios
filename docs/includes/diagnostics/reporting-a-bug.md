## Report a problem

If this diagnostic appears to be incorrect, [report the error or warning](https://github.com/dotnet/macios/issues/new?template=06-diagnostic.yml). Include the full message, a minimal reproduction, your .NET SDK and workload versions, and a [binary build log](https://github.com/dotnet/macios/wiki/Diagnosis#binary-build-logs).

Review logs for credentials and other private information before uploading them.
