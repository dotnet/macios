# .NET for Apple platforms error/warning MT0028

> [!NOTE]
> This page preserves a historical diagnostic. Some instructions apply only to older Xamarin tooling or project types.

## Issue

Cannot enable PIE (-pie) when targeting iOS 4.1 or earlier. Please disable PIE (-pie:false) or set the deployment target to at least iOS 4.2

## Solution

This error is no longer shown (it's not possible to target iOS 4.1 or earlier anymore, iOS 6.0 is the minimum).
